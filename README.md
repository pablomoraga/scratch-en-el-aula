# Scratch en el aula · Aprende Scratch con Robit

Manual propio para aprender a programar con Scratch 3.0 en Primaria y ESO: 7 apartados, 70 retos, 11 talleres (3 de club y 8 de efemérides) y más de 100 proyectos .sb3, con imagen en estilo 8 bits.

**Web:** https://pablomoraga.github.io/scratch-en-el-aula/

La web se construye automáticamente desde la carpeta `generador/` cada vez que se guarda un cambio. Para editarla, consulta **[GUIA-EDICION.md](GUIA-EDICION.md)**.
